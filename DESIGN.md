## 1. DESIGN READ

**Reading this as:** геймифицированная обучающая воронка в Telegram Mini App для российских
перформанс-маркетологов (Директ / Авито / таргет), язык — **точный измерительный прибор
полевой лаборатории**, склоняемся к тёмному приборному интерфейсу с одним сигнальным акцентом,
моно-микротипографикой и физическим ощущением панели.

**Дилы:** `DESIGN_VARIANCE: 7` · `MOTION_INTENSITY: 7` · `VISUAL_DENSITY: 5`

### Ядро идентичности

Текст в продукте — грубый, разговорный, матерный, деконструирующий («бабки», «херня»,
«головой об Enter ударился»). Интерфейс — **противоположность**: холодный, выверенный,
лабораторный, с маркировкой узлов и калибровочными шкалами.

**Этот контраст и есть дизайн.** Прибор измеряет, где маркетолог теряет деньги,
и хладнокровно печатает результат. Юмор берётся из копирайта, не из интерфейса.
Интерфейс никогда не шутит — он замеряет.

### Референсы (правильные)

| Референс | Что берём |

Sci-Fi HUD из фильмов · Cyberpunk 2077 · Matrix · «AI-фиолетовый градиент» ·
Glassmorphism на всём · Duolingo-мультяшность · корпоративный EdTech.

## 2. ЗАПРЕТЫ (жёсткие)

1. **Нет неоново-циановой HUD-эстетики.** Никакого `#00FFFF`, `#00FF00`, `#FF00FF`.
2. **Нет AI-фиолетового / индиго-градиента** (`#6366F1`, `#8B5CF6` и родня) — ни в кнопках, ни в свечении.
3. **Нет чистого `#000000`** как фона и **нет чистого `#FFFFFF`** как текста.
4. **Нет glassmorphism** (`backdrop-filter: blur` на карточках). Глубина = слои + волосяная линия + верхний блик.
5. **Нет эмодзи** в интерфейсе. Иконки — только Phosphor. Ни одного эмодзи в UI-тексте.
6. **Нет рукописных SVG-иконок.** Только `@phosphor-icons/react`, `weight="regular"` по умолчанию, `duotone` запрещён.
7. **Нет второго акцентного цвета** для украшения. `--warn` и `--bad` — только семантика (потеря денег / неверный ответ).
8. **Нет бесконечных зацикленных анимаций** кроме: пульс статуса «замер идёт» и курсор в поле кода.
9. **Нет Inter.** Шрифты зафиксированы в §4.
10. **Нет `h-screen`.** Только `min-h-[100dvh]` + safe-area.
11. **Нет скруглений > 16px** и нет `rounded-full` на контейнерах (только на точках-статусах и аватарах).
12. **Нет теней-размывов** (`box-shadow: 0 10px 40px rgba(0,0,0,.5)`). Глубина — через слои и линии, не через blur.

## 3. ЦВЕТ

Одна палитра на весь проект. Холодный графит + один сигнальный акцент.

```css
/* Поверхности — снизу вверх по высоте */
--bg-void:      #08090B;  /* фон приложения */
--bg-panel:     #0E1013;  /* основная панель / карточка */
--bg-raised:    #16191D;  /* приподнятый элемент, инпут, чип */
--bg-sunken:    #050607;  /* колодец: слоты кода, поле показаний */

/* Линии — волосяные, всегда 1px */
--line:         rgba(255,255,255,0.075);
--line-strong:  rgba(255,255,255,0.14);
--line-signal:  rgba(198,242,78,0.32);

/* Текст */
--ink:          #EDEFF2;  /* основной */
--ink-muted:    #9AA2AB;  /* вторичный, описания */
--ink-faint:    #5C646D;  /* лейблы, служебное */
--ink-invert:   #08090B;  /* текст на сигнальной заливке */

/* СИГНАЛ — единственный акцент */
--signal:       #C6F24E;
--signal-deep:  #A8D42F;  /* pressed-состояние */
--signal-dim:   rgba(198,242,78,0.12);  /* заливка-подложка */
--signal-glow:  rgba(198,242,78,0.20);  /* только для focus-ring */

/* Семантика — НЕ для украшения */
--warn:         #FFA53D;  /* утечка денег, предупреждение */
--warn-dim:     rgba(255,165,61,0.12);
--bad:          #FF5A45;  /* неверный ответ, ошибка кода */
--bad-dim:      rgba(255,90,69,0.12);
```

**Правила:**
- Первичная CTA = **сплошная заливка `--signal`, текст `--ink-invert`**. Одна такая кнопка на экран. Это самый яркий объект в приложении, он всегда «что делать дальше».
- Вторичная кнопка = прозрачная, `1px solid var(--line-strong)`, текст `--ink`.
- `--warn` появляется **только** рядом с числом потерянных денег и в блоках «где ты теряешь».
- `--bad` появляется **только** на неверном ответе / неверном коде.
- Контраст: `--signal` на `--bg-void` ≈ 14:1; `--ink-muted` на `--bg-panel` ≈ 6.4:1. Ниже 4.5:1 не опускаться.

## 4. ТИПОГРАФИКА

Кириллица обязательна. Оба шрифта — self-hosted через `@fontsource-variable`, никаких `<link>` на Google Fonts.

- **Onest Variable** — весь интерфейс и заголовки. Современный гротеск с отличной кириллицей, не Inter.
- **JetBrains Mono Variable** — лейблы, коды, показания, числа, статусы.

```css
--font-sans: 'Onest Variable', system-ui, sans-serif;
--font-mono: 'JetBrains Mono Variable', ui-monospace, monospace;
```

### Шкала (mobile-first, вьюпорт Telegram ≈ 390px)

| Токен | Размер / интерлиньяж | Трекинг | Вес | Применение |
|---|---|---|---|---|
| `display-xl` | 34px / 1.02 | -0.03em | 700 | Герой экрана, один на экран |
| `display-l` | 28px / 1.06 | -0.025em | 700 | Заголовок экрана |
| `h1` | 22px / 1.18 | -0.02em | 600 | Заголовок блока |
| `h2` | 18px / 1.28 | -0.015em | 600 | Подзаголовок |
| `body` | 16px / 1.55 | -0.005em | 400 | Основной текст |
| `body-s` | 14px / 1.5 | 0 | 400 | Вторичный текст |
| `label` | 11px / 1.2 | **+0.14em** | 500 | МОНО, UPPERCASE, служебная маркировка |
| `readout` | 40px / 1 | -0.02em | 600 | МОНО, `tabular-nums`, крупные показания |
| `readout-s` | 15px / 1.3 | +0.02em | 500 | МОНО, `tabular-nums`, мелкие числа |

**Правила:**
- Все числа — `font-variant-numeric: tabular-nums` в моно. Всегда. Числа не должны прыгать при анимации счётчика.
- Заголовки-герои: максимум **~26ch** ширины, перенос ручной через `<br/>` не делать — использовать `text-wrap: balance`.
- Основной текст: `max-width: 42ch`.
- Лейбл-маркировка всегда в формате `МОДУЛЬ 01 · АУДИТОРИЯ` — моно, uppercase, `--ink-faint`.
- Разговорный текст автора идёт короткими абзацами (1–2 строки), как в исходнике. Не склеивать в простыни: ритм рубленых абзацев — часть голоса.
- Цитаты автора (в исходнике `>`): отдельный стиль — левая линия `2px solid var(--line-strong)`, `padding-left: 14px`, `--ink-muted`, курсив НЕ применять.

## 5. ПРОСТРАНСТВО И СЕТКА

```css
--sp-1: 4px;  --sp-2: 8px;   --sp-3: 12px;  --sp-4: 16px;
--sp-5: 24px; --sp-6: 32px;  --sp-7: 48px;  --sp-8: 64px;

--radius-sm: 6px;   /* чипы, мелкие элементы */
--radius-md: 10px;  /* кнопки, инпуты */
--radius-lg: 14px;  /* панели, карточки */

--gutter: 20px;                 /* боковые поля экрана */
--app-max: 480px;               /* максимальная ширина контента */
--bar-h: 76px;                  /* высота нижней панели действия */
```

- Контент центрируется: `max-width: var(--app-max); margin-inline: auto;`
- Боковые поля `--gutter` **везде одинаковые**. Ничего не выходит за них, кроме калибровочных шкал и полноширинных разделителей — они намеренно уходят в край экрана.
- Safe-area: `padding-top: max(var(--sp-4), env(safe-area-inset-top))`, аналогично снизу.
- Раскладка — только CSS Grid. Никакой flex-математики с процентами.
- Вертикальный ритм внутри экрана: `--sp-5` между смысловыми блоками, `--sp-3` внутри блока.

## 6. ФИРМЕННЫЕ ЭЛЕМЕНТЫ (сигнатура)

Это то, что делает интерфейс узнаваемым. Каждый обязателен хотя бы раз.

### 6.1 Калибровочная шкала (`TickRail`)
Горизонтальная линейка из рисок разной высоты, как на измерительном приборе.
Реализация: `repeating-linear-gradient`, риски 1px, шаг 6px, каждая 5-я риска выше.
Используется: как прогресс-рельс сверху, как разделитель секций, как декор в колодцах.
Пройденная часть окрашивается в `--signal`, будущая — в `--line`.

### 6.2 Маркировка узла (`NodeLabel`)
Моно-лейбл в левом верхнем углу каждой панели: `М-01 · АУДИТОРИЯ` + статус-точка
(4px круг: `--ink-faint` заперто / `--signal` активно / пульсирующий `--warn` — идёт замер).

### 6.3 Колодец показаний (`Well`)
Утопленная область: фон `--bg-sunken`, `inset 0 1px 0 rgba(0,0,0,0.6)`, сверху волосяная
`--line`. Внутри — крупные моно-числа. Используется для счётчика утечки и слотов кода.

### 6.4 Верхний блик панели
Каждая панель получает `box-shadow: inset 0 1px 0 rgba(255,255,255,0.05)`.
Имитирует освещённое ребро металлической панели. Это заменяет тени и glassmorphism.

### 6.5 Зерно (`Grain`)
Фиксированный оверлей на всё приложение: SVG `feTurbulence` (baseFrequency 0.9),
`opacity: 0.028`, `mix-blend-mode: overlay`, `pointer-events: none`, `position: fixed`.
Убивает «плоскую цифру», даёт физику. Один раз в `App`, не в компонентах.

### 6.6 Скан-линия (`ScanLine`)
Тонкая горизонтальная линия `--signal`, единожды проходящая сверху вниз по панели
в момент «замера». **Не зациклена.** Только на событии, длительность 700ms.

## 7. КОМПОНЕНТЫ — ВИЗУАЛЬНЫЕ СПЕЦИФИКАЦИИ

### Button (primary)
`height: 54px; border-radius: var(--radius-md); background: var(--signal);
color: var(--ink-invert); font: 600 16px/1 var(--font-sans); letter-spacing: -0.01em;`
Полная ширина в нижней панели. Press: `scale(0.985)` + `background: var(--signal-deep)`, 90ms.
Disabled: `background: var(--bg-raised); color: var(--ink-faint);` без прозрачности.

### Button (secondary / ghost)
`height: 54px; background: transparent; border: 1px solid var(--line-strong); color: var(--ink);`
Press: `background: var(--bg-raised)`.

### Choice (вариант ответа)
`min-height: 56px; background: var(--bg-panel); border: 1px solid var(--line);
border-radius: var(--radius-md); padding: 14px 16px; text-align: left;`
Слева — моно-индекс `01`…`04` цветом `--ink-faint`, `width: 24px`.
Selected: `border-color: var(--line-signal); background: var(--signal-dim);` индекс → `--signal`.
Correct: индекс заменяется на иконку `Check` цвета `--signal`, левая грань 2px `--signal`.
Wrong: левая грань 2px `--bad`, короткий `shake` (±4px, 220ms).
Тап-таргет минимум 48px. Между вариантами `--sp-2`.

### CodeInput (ключевое слово)
Ряд утопленных слотов-колодцев по числу букв кода. Моно, uppercase, 22px, центрирование.
Скрытый `<input>` ловит ввод; слоты — визуализация. Заполненный слот: текст `--ink`,
нижняя грань 2px `--signal`. Активный слот: мигающий курсор-линия `--signal` (1s steps).
Ошибка: все слоты → грань `--bad`, `shake`, затем очистка через 400ms.
Успех: слоты последовательно вспыхивают `--signal` (stagger 45ms) → `ScanLine` по панели → переход.

### Readout (счётчик)
Моно `tabular-nums`, размер `readout`. Анимация числа — `motion` spring на motionValue,
**не** через `useState` на каждый кадр. Знак валюты `₽` — на 0.55em меньше, `--ink-muted`.

### ProgressRail (верхний рельс)
Закреплён сверху, высота 40px, фон `--bg-void` с нижней волосяной `--line`.
Слева — `TickRail` c залитой пройденной долей. Справа — моно-показание `47%`.
Под рельсом — 4 фазы: `ЗНАЮ · ХОЧУ · ВЕРЮ · ПЛАЧУ`, активная фаза `--signal`,
пройденные `--ink-muted`, будущие `--ink-faint`.
**Да, фазы воронки показываются пользователю открыто** — это соответствует голосу
продукта («разоблачение состоялось до начала прогрева») и является частью POV.

### Panel
`background: var(--bg-panel); border: 1px solid var(--line);
border-radius: var(--radius-lg); box-shadow: inset 0 1px 0 rgba(255,255,255,0.05);`
Внутренние поля `--sp-4`. Сверху опционально `NodeLabel`.

### VideoBlock
Постер 16:9, `--radius-lg`, поверх — кнопка Play (56px круг `--signal`, иконка `Play` чёрная).
Под постером строка: моно `ВИДЕО 01 · 12:40` слева, статус справа
(`НЕ ПРОСМОТРЕНО` / `ИДЁТ` / `ПРОСМОТРЕНО` цветом `--signal`).
Прогресс просмотра — `TickRail` под постером.

## 8. ДВИЖЕНИЕ

Все пружины и длительности берутся из `src/lib/motion.ts`. Никаких инлайновых магических чисел.

```ts
springSnappy = { type:'spring', stiffness: 420, damping: 34, mass: 0.85 }  // кнопки, чипы
springPanel  = { type:'spring', stiffness: 280, damping: 32, mass: 1.0 }   // панели, шторки
springSoft   = { type:'spring', stiffness: 180, damping: 26, mass: 1.1 }   // крупные счётчики
easeOut      = [0.16, 1, 0.3, 1]                                          // непружинные
```

- **Переход между экранами:** исходящий `opacity 1→0, x 0→-16px` за 160ms; входящий
  `opacity 0→1, x 20px→0` со `springPanel`. Прогресс-рельс анимируется одновременно.
- **Появление списка:** stagger 40ms, каждый элемент `y 10px→0, opacity 0→1`, `easeOut` 260ms.
- **Загрузка экрана-прибора:** сначала рисуется `TickRail` (scaleX 0→1, 400ms), затем
  проявляется лейбл, затем контент. Только на ключевых экранах (результат теста, разблокировка модуля).
- **Тактильная отдача (Telegram Haptics) — обязательна:**
  `impactOccurred('light')` — выбор варианта, ввод символа кода;
  `impactOccurred('medium')` — первичная CTA;
  `notificationOccurred('success')` — верный код, разблокировка модуля;
  `notificationOccurred('error')` — неверный код;
  `selectionChanged()` — переключение табов/фильтров.
  Всё через `src/lib/telegram.ts`, с no-op в браузере.
- **`prefers-reduced-motion`:** все `transform`/`x`/`y`/`scale` отключаются, остаётся
  только `opacity` за 120ms. Счётчики ставят финальное значение сразу. Скан-линия не рисуется.

## 9. ДОСТУПНОСТЬ И УСТОЙЧИВОСТЬ

- Тап-таргеты ≥ 44×44px, между интерактивами ≥ 8px.
- `:focus-visible` — `outline: 2px solid var(--signal); outline-offset: 2px`. Никогда не `outline: none` без замены.
- Каждый интерактивный элемент — нативный `<button>` / `<input>`, не `<div onClick>`.
- Все состояния (loading / empty / error / disabled) спроектированы, не оставлены дефолтными.
- Длинный русский текст не ломает раскладку: `overflow-wrap: anywhere` на контейнерах текста.
- Тема Telegram игнорируется намеренно: приложение принудительно тёмное, брендированное
  (`setHeaderColor('#08090B')`, `setBackgroundColor('#08090B')`). Это осознанное решение,
  фиксированная айдентика важнее подстройки под тему клиента.
