> отменены целиком: обе читались как один и тот же тёмный технический интерфейс.

## 1. DESIGN READ

**Reading this as:** обучающая воронка в Telegram Mini App для российских перформанс-маркетологов,
язык — **брутально-редакционный шоурум на тёплом сером холсте**: почти монохромный канвас,
огромная сжатая заглавная типографика, абсолютно плоские поверхности, крупные радиусы,
единственный хроматический акцент — бледная мята.

**Тема:** светлая. **Дилы:** `DESIGN_VARIANCE: 7` · `MOTION_INTENSITY: 4` · `VISUAL_DENSITY: 4`

### Ядро идентичности

**Всю эмоциональную работу делает типографика.** Не цвет, не анимация, не эффекты.
Сжатые заглавные заголовки с интерлиньяжем 0.9 нависают над спокойным текстом 16px —
драматический контраст масштаба и есть выразительное средство.

Глубина создаётся **контрастом поверхностей**, а не тенями: серый холст → белая карточка →
чёрный инверсный блок. Ни одной тени, ни одного градиента, ни одного эффекта высоты.

Мотион здесь сдержаннее, чем в прошлых версиях: редакционный печатный мир не суетится.

| Референс | Что берём |

Тёмные технические интерфейсы · неон · киберпанк · glassmorphism · тени и градиенты ·
AI-фиолетовый · химическая лаборатория (**это была v2, отменена**).

## 2. ЗАПРЕТЫ (жёсткие)

1. **Нет теней.** Ни `box-shadow`, ни `filter: drop-shadow`, ни имитаций высоты. Система плоская намеренно.
2. **Нет градиентов.** Ни на фонах, ни на кнопках, ни на текстах.
3. **Нет чистого белого как фона страницы.** Фон всегда `--canvas` `#E5E5E5`. Белый — только карточки.
4. **Нет хроматических заливок больших поверхностей.** Мята и жёлтый — только мелкие элементы: теги, подсветка, точки.
5. **Заголовки только заглавными.** Дисплейные и вторичные заголовки — `text-transform: uppercase`, всегда.
6. **Интерлиньяж дисплейных заголовков не выше 0.95.** Плотное сжатие — это и есть приём.
7. **Сжатый шрифт не применять мельче 28px.** Он спроектирован под крупный набор, в мелком кегле не читается.
8. **Нет серых волосяных рамок на карточках** там, где разделение можно дать контрастом поверхностей.
9. **Нет эмодзи.** Иконки — только Phosphor, `weight="regular"`, моно-линейные.
10. **Нет зерна, шума, текстур и световых пятен.** Мир плоский и чистый (в v2 это было, снято).
11. **Нет `h-screen`.** Только `min-h-[100dvh]` + safe-area.
12. **Нет фаз воронки на экране.** ЗНАЮ / ХОЧУ / ВЕРЮ / ПЛАЧУ — внутренняя механика, пользователю не показывается.
13. **Видео — это видео.** Никаких расшифровок и пересказов под плеером.
14. **Нет текста мельче 12px.**

## 3. ЦВЕТ

Почти монохром. Один хроматический акцент плюс один микроакцент.

```css
/* Поверхности */
--canvas:        #E5E5E5;  /* фон приложения — тёплый серый, НЕ белый */
--card:          #FFFFFF;  /* карточка, основная контентная поверхность */
--inverted:      #000000;  /* инверсный блок — драматический контраст */
--mist:          #F3F3F3;  /* тихая подложка, вторичная панель, поля ввода */

/* Текст */
--ink:           #000000;  /* основной текст, заголовки */
--ink-secondary: #444444;  /* вторичный текст, подзаголовки */
--ink-muted:     #979797;  /* мета, служебные подписи */
--ink-inverted:  #FFFFFF;  /* текст на чёрном */

/* Структура */
--hairline:      #C6C6C6;  /* границы, разделители, отключённые состояния */
--graphite:      #2F2F2F;  /* глубокая поверхность, тяжёлый акцент */

/* Акценты — ТОЛЬКО мелкие элементы */
--mint:          #D1FFCA;  /* теги, подложка выбранного, статус «сделано» */
--voltage:       #FFF100;  /* микроакцент: подсветка слова, точка-маркер */

/* Функциональное — минимально необходимое сверх референса */
--alert:         #D92D20;  /* ТОЛЬКО ошибка: неверный ответ, неверный код */
```

**Правила:**
- **Первичная CTA** = заливка `--inverted`, текст `--ink-inverted`, радиус `--r-button`.
  Самый контрастный интерактивный элемент экрана. Одна на экран.
- **Вторичная кнопка** = прозрачная, `1.5px solid var(--ink-secondary)`, текст `--ink-secondary`.
- **Третичная** = текстовая ссылка, `--ink`, подчёркивание.
- `--mint` — теги, подложка выбранного варианта, статус «сделано». Всегда с текстом `--ink`.
- `--voltage` — только микроэлементы: подсветка слова, точка-маркер, короткий всплеск. Никогда не фон блока.
- `--alert` — только состояние ошибки, на тексте и границе, не заливкой. В референсе такого цвета нет,
  он добавлен как функциональная необходимость: без него неверный ответ в тесте нечем показать.
- Контраст: `--ink` на `--canvas` ≈ 15:1, `--ink-secondary` ≈ 7.5:1.
  `--ink-muted` на `--card` ≈ 3.9:1 — поэтому **только служебные подписи**, не смысловой текст.

## 4. ТИПОГРАФИКА

Кириллица обязательна. Всё self-hosted через `@fontsource`, без `<link>` на Google Fonts.

| Роль | Шрифт | Почему именно он |
|---|---|---|
| Дисплей, сжатый заглавный | **Oswald** (700) | Ближайший рабочий аналог Suisse Intl Cond **с полной кириллицей**. Anton, Bebas Neue и Barlow Condensed кириллицы не имеют, русские заголовки на них не наберутся |
| Тело, интерфейс | **Onest** (400/500/600) | Неогротеск в духе Suisse Intl, кириллица полная |
| Моно-лейблы | **JetBrains Mono** (400) | Техническая аннотация, кириллица полная |

```css
--font-display: 'Oswald Variable', 'Oswald', system-ui, sans-serif;
--font-sans:    'Onest Variable', system-ui, sans-serif;
--font-mono:    'JetBrains Mono Variable', ui-monospace, monospace;
```

### Шкала — адаптирована под Telegram Mini App

Референс задан для десктопа (дисплей 130px). В мини-аппе вьюпорт ≈ 360–430px, поэтому шкала
пересчитана: пропорции и драматизм сохранены, кегли реальные для мобильного.
Дисплейные размеры — через `clamp()`, чтобы на узких экранах не переполнялись.

| Токен | Размер | Интерлиньяж | Трекинг | Шрифт / вес | Применение |
|---|---|---|---|---|---|
| `display-xl` | `clamp(44px, 13.5vw, 72px)` | 0.90 | -0.03em | Oswald 700, UPPERCASE | Герой экрана, один на экран |
| `display` | `clamp(34px, 10.5vw, 56px)` | 0.90 | -0.03em | Oswald 700, UPPERCASE | Заголовок экрана |
| `heading-lg` | 28px | 0.92 | -0.02em | Oswald 700, UPPERCASE | Заголовок крупного блока |
| `heading` | 22px | 1.10 | -0.02em | Onest 500, UPPERCASE | Заголовок карточки, вторичный |
| `subheading` | 18px | 1.33 | -0.011em | Onest 500 | Подзаголовок |
| `body` | 16px | 1.45 | -0.01em | Onest 400 | Основной текст |
| `body-sm` | 14px | 1.35 | -0.011em | Onest 400 | Вторичный текст, мета |
| `caption` | 12px | 1.5 | -0.03em | JetBrains Mono 400, UPPERCASE | Лейблы, нумерация, аннотация |

**Правила:**
- Дисплей и `heading-lg`/`heading` — **всегда заглавными**. Строчных заголовков в системе нет.
- Oswald ниже 28px не применять (§2.7). Мелкие заголовки — Onest 500 uppercase.
- Мера основного текста ≤ 40ch. Дисплейные заголовки — до 14ch: они должны ломаться
  на 3–4 плотные строки, это и создаёт брутальный блок.
- Все числа — `tabular-nums`.
- Рубленые короткие абзацы автора сохраняются отдельными `<p>`.
- На кеглях 28–34px трекинг Oswald ослабить до -0.02em: в кириллице при -0.03em буквы начинают липнуть.

## 5. ПРОСТРАНСТВО И ФОРМА

Базовая единица 8px, плотность комфортная.

```css
--sp-1: 8px;   --sp-2: 16px;  --sp-3: 24px;
--sp-4: 40px;  --sp-5: 64px;  --sp-6: 80px;

/* Радиусы адаптированы под мобильный: референсные 24–64px пересчитаны,
   потому что 64px на карточке шириной 320px съедает всю форму. */
--r-button:   8px;   /* кнопки, поля */
--r-input:    8px;
--r-card:     20px;  /* обычная карточка */
--r-card-lg:  28px;  /* полноширинный блок, инверсная секция */
--r-arc:      28px;  /* верхняя арка: 28px 28px 0 0 */
--r-pill:     999px; /* теги, чипы */

--gutter:      16px; /* боковые поля экрана */
--app-max:     480px;
--section-gap: 40px; /* вертикальный ритм (референсные 80px / 2 для мобильного) */
--card-pad:    20px;
--bar-h:       76px; /* нижняя панель действия */
```

- Контент центрируется, `max-width: var(--app-max)`.
- Safe-area обязательна сверху и снизу.
- Раскладка — только CSS Grid.
- Скругления **крупные и намеренные**: это часть языка, а не смягчение.

## 6. КОМПОНЕНТЫ

### Карточка (`Panel`)
`background: var(--card); border-radius: var(--r-card); padding: var(--card-pad);`
**Без тени. Без рамки.** Отделяется от холста только контрастом поверхности.

### Инверсный блок
`background: var(--inverted); border-radius: var(--r-card-lg); color: var(--ink-inverted);`
Для секций, которые должны разорвать светлый ритм: результат теста, кульминация, продающий блок.
Использовать редко — два-три раза на всю воронку, иначе приём стирается.

### Арка (`--r-arc`)
`border-radius: 28px 28px 0 0` — блок, «выходящий» снизу. Для открывающих секций и нижних панелей.

### Кнопка первичная
Чёрная заливка, белый текст, `--r-button`, высота 52px, Onest 500 16px.
Press: `opacity 0.85`. Disabled: `background: var(--hairline); color: var(--ink-muted);`

### Кнопка вторичная
Прозрачная, `1.5px solid var(--ink-secondary)`, текст `--ink-secondary`, высота 52px.

### Тег (`Chip`)
`background: var(--mint); color: var(--ink); border-radius: var(--r-pill); padding: 6px 14px;`
Моно `caption`. Подписной акцент системы.

### Вариант ответа (`Choice`)
Белая карточка, `--r-card`, минимум 56px, слева моно-индекс `01` цветом `--ink-muted`.
- `selected` — заливка `--mint`, индекс `--ink`.
- `correct` — заливка `--mint`, слева иконка `Check`.
- `wrong` — `1.5px solid var(--alert)`, короткий shake.

### Поле кода (`CodeInput`)
Ряд слотов: `background: var(--mist); border-radius: var(--r-input);` моно, заглавные, 22px.
Активный слот — нижняя граница 2px `--ink`. Ошибка — граница `--alert` + shake.
Успех — слоты последовательно заливаются `--mint`.

### Поле ввода практики (`TextArea`)
`background: var(--mist); border-radius: var(--r-input); border: none;` Onest 16px.
Focus — `outline: 2px solid var(--ink)`. Минимум 96px высоты.

### Прогресс (`ProgressRail`)
Тонкая линия сверху: трек `--hairline`, пройденная часть `--ink`, высота 3px.
Плюс моно-подпись `caption` вида `ШАГ 07 / 25`. **Фазы воронки не показывает.**
Калибровочной шкалы из v1/v2 больше нет — она была из другого мира.

### Видеоблок (`VideoBlock`)
Обложка 16:9, `--r-card`. Кнопка Play — чёрный круг 56px, иконка белая.
Под обложкой моно `caption`: название и хронометраж, справа статус.
Прогресс — линия `--ink` на треке `--hairline`. **Без описания и расшифровки.**

### Моно-лейбл (`caption`)
Техническая аннотация: `МОДУЛЬ 01`, `ШАГ 07 / 25`, `ВОПРОС 03 / 06`.
Цвет `--ink-muted`, заглавные, JetBrains Mono 12px.

## 7. ДВИЖЕНИЕ

Редакционный печатный мир сдержан. `MOTION_INTENSITY: 4` — заметно тише прошлых версий.

```ts
springSnappy = { type:'spring', stiffness: 420, damping: 34, mass: 0.85 }  // кнопки, чипы
springPanel  = { type:'spring', stiffness: 280, damping: 32, mass: 1.0 }   // панели
easeOut      = [0.16, 1, 0.3, 1]
```

- **Переход экрана:** только `opacity` + короткий `y` 8px. Никаких горизонтальных пролётов.
- **Появление списка:** stagger 40ms, `opacity` + `y` 8px.
- **Заголовок:** допустимо появление построчно (маска по строкам) — единственный дисплейный эффект,
  и он уместен, потому что типографика здесь главный герой.
- **Никаких зацикленных анимаций** кроме курсора ввода и индикатора набора в чате.
- Haptics: `light` — выбор, `medium` — первичная CTA, `success` — верный код, `error` — неверный, `select` — переключение.
- `prefers-reduced-motion`: остаётся только `opacity` 120ms.

## 8. ДОСТУПНОСТЬ И ПЛАТФОРМА

- Тап-таргеты ≥ 44×44px, зазор ≥ 8px.
- `:focus-visible` — `outline: 2px solid var(--ink); outline-offset: 2px`.
- Только нативные `<button>` / `<input>` / `<textarea>`.
- Спроектированы все состояния: loading, empty, error, disabled.
- `overflow-wrap: anywhere` на контейнерах текста.
- **Тема принудительно светлая.** Telegram: `setHeaderColor` и `setBackgroundColor` читают
  реальное значение `--canvas`. Тема клиента игнорируется намеренно.
- Проверить в Telegram при включённой тёмной теме клиента: приложение остаётся светлым
  и не мигает тёмным на старте.
