## 1. DESIGN READ

**Reading this as:** геймифицированная обучающая воронка в Telegram Mini App для российских
перформанс-маркетологов, язык — **подпольная химическая лаборатория Breaking Bad,
переосмысленная как современная измерительная станция**, тёплая пустынная тьма
с ядовито-зелёным сигналом и холодным «голубым» цветом результата.

**Дилы:** `DESIGN_VARIANCE: 8` · `MOTION_INTENSITY: 7` · `VISUAL_DENSITY: 5`

### Ядро идентичности

Копирайт грубый, разговорный, матерный. Интерфейс — холодная лаборатория,
которая молча замеряет и выдаёт результат. Этот контраст и есть дизайн.

Но лаборатория теперь не абстрактно-приборная, а **конкретная**: ночь в пустыне,
натриевый свет, химзащита, стекло, кристалл. Человек не проходит курс — он ставит
опыт над собственной работой и получает вещество на выходе.

### Референсы

| Референс | Что берём |
|---|---|
| Титры Breaking Bad | **Клетка периодической таблицы** — несущий графический приём (см. §6.1) |
| Цветокор сериала | Тёплая пустынная тьма, натриевый свет, выжженная охра, ржавчина |
| «Blue Sky» | Холодный голубой как цвет достигнутого результата, и только его |
| Химзащита / хазмат | Ядовитый жёлто-зелёный как сигнальный цвет действия |
| Лабораторное стекло | Прозрачность, грани, преломление — в мелких деталях, не в фонах |
| Современная приборная панель | Крупные показания, tabular-цифры, точность, читаемость |

### Анти-референсы

Sci-Fi HUD · Cyberpunk · Matrix · неоновый циан на чёрном · AI-фиолетовый градиент ·
glassmorphism · холодный графит с лаймом (**это была версия 1, она запрещена**).

## 2. ЗАПРЕТЫ (жёсткие)

1. **Не показывать пользователю фазы воронки.** ЗНАЮ / ХОЧУ / ВЕРЮ / ПЛАЧУ — внутренняя
   механика прогрева. Она ведёт человека через копирайт, контент и интерактив, но **никогда
   не выводится на экран**. Ни в прогресс-баре, ни лейблом, ни подписью. Объяснять человеку,
   по какой схеме им управляют, — значит разрушать саму схему.
2. **Видео — это видео.** Запрещено выводить расшифровки, пересказы и «содержание ролика»
   текстом под плеером. Сценарии видео — это смысл, который несут **экраны вокруг видео**:
   подводка, интерактив, механика, вывод. Экран видео содержит максимум: обложку, название,
   хронометраж, одну фразу-ставку и предупреждение про ключевое слово. Ничего больше.
3. **Нет холодного графита с лаймом** (палитра v1). База тёплая, см. §3.
4. **Нет чистого `#000000`** и **нет чистого `#FFFFFF`**.
5. **Нет неонового циана, matrix-зелёного, AI-фиолетового.**
6. **Нет glassmorphism.** Глубина — слои, грань, верхний блик.
7. **Нет эмодзи.** Иконки — только Phosphor, `weight="regular"`.
8. **Нет рукописных SVG-иконок.**
9. **Голубой `--sky` — не украшение.** Он означает ровно одно: результат получен.
   Появляется на разблокированном модуле, на собранной цепочке, на успешном коде. Больше нигде.
10. **Нет бесконечных зацикленных анимаций** кроме курсора ввода и индикатора набора в чате.
11. **Нет `h-screen`.** Только `min-h-[100dvh]` + safe-area.
12. **Нет теней-размывов.** Глубина через слои и грани.
13. **Нет текста мельче 12px** и **нет трекинга больше +0.10em** на кириллице.

## 3. ЦВЕТ

Пустынная ночь под натриевым светом. Тёплая тьма, а не синеватая.

```css
/* Поверхности — тёплая тьма */
--bg-void:      #0B0A07;  /* фон приложения */
--bg-panel:     #14120D;  /* панель, карточка */
--bg-raised:    #1E1A13;  /* приподнятый элемент, инпут, чип */
--bg-sunken:    #060502;  /* колодец: слоты кода, показания */

/* Линии — заметно плотнее, чем в v1 (это была ошибка читаемости) */
--line:         rgba(240,232,214,0.11);
--line-strong:  rgba(240,232,214,0.20);
--line-acid:    rgba(169,196,15,0.38);

/* Текст — тёплый, высокий контраст */
--ink:          #F2EDE1;  /* основной, ~15:1 на панели */
--ink-muted:    #B0A692;  /* вторичный, ~8:1 — было 6.4:1 и читалось плохо */
--ink-faint:    #7A7263;  /* служебное, ~4.7:1 */
--ink-invert:   #0B0A07;  /* текст на заливке */

/* КИСЛОТА — сигнал действия. Химзащита, титры сериала. */
--acid:         #A9C40F;
--acid-deep:    #8CA30B;  /* pressed */
--acid-dim:     rgba(169,196,15,0.14);

/* НЕБО — результат получен. Только это, ничего декоративного. */
--sky:          #5BC8E8;
--sky-dim:      rgba(91,200,232,0.14);

/* Семантика */
--rust:         #C4551D;  /* утечка денег, предупреждение */
--rust-dim:     rgba(196,85,29,0.14);
--bad:          #D93A2B;  /* ошибка, неверный ответ */
--bad-dim:      rgba(217,58,43,0.14);
```

**Правила:**
- Первичная CTA = заливка `--acid`, текст `--ink-invert`. Одна на экран.
- Вторичная = прозрачная, `1px solid var(--line-strong)`, текст `--ink`.
- `--rust` — только рядом с числом потерянных денег и в блоках «где ты теряешь».
- `--sky` — только разблокированный модуль, успешный код, собранная цепочка.
- Ниже 4.5:1 не опускаться нигде. `--ink-faint` не использовать для смыслового текста,
  только для служебных подписей.

Шрифты те же (кириллица обязательна, self-hosted через `@fontsource-variable`):

### Шкала — переработана под читаемость

| Токен | Размер / интерлиньяж | Трекинг | Вес | Применение |
|---|---|---|---|---|
| `display-xl` | 34px / 1.06 | -0.028em | 700 | Герой экрана, один на экран |
| `display-l` | 28px / 1.10 | -0.022em | 700 | Заголовок экрана |
| `h1` | 22px / 1.22 | -0.018em | 600 | Заголовок блока |
| `h2` | 18px / 1.32 | -0.012em | 600 | Подзаголовок |
| `body` | **17px / 1.62** | -0.003em | 400 | Основной текст (было 16/1.55) |
| `body-s` | **15px / 1.55** | 0 | 400 | Вторичный текст (было 14/1.5) |
| `label` | **12px / 1.25** | **+0.10em** | 500 | МОНО, UPPERCASE (было 11 / +0.14em) |
| `readout` | 40px / 1 | -0.02em | 600 | МОНО, `tabular-nums` |

**Правила:**
- Все числа — `tabular-nums`. Всегда.
- Заголовки: `text-wrap: balance`, ширина ≤ 26ch.
- Основной текст: `max-width: 42ch`.
- Рубленые короткие абзацы автора сохраняются как отдельные `<p>`.

## 6. ФИРМЕННЫЕ ЭЛЕМЕНТЫ

### 6.1 КЛЕТКА ЭЛЕМЕНТА (`ElementTile`) — несущий приём всей системы

Прямоугольная клетка периодической таблицы. Это главный узнаваемый объект приложения.

Состав клетки:
- **атомный номер** — моно 12px, левый верхний угол, `--ink-faint`;
- **символ** — две кириллические буквы, `symbol` 30px, центр;
- **название** — 12px, под символом, `--ink-muted`;
- **«атомная масса»** — моно 12px, низ: **процент утечки, который закрывает модуль**.
  Это не декорация: число настоящее и берётся из `LEAK_WEIGHTS`.

Три модуля воронки:

| № | Символ | Название | «Масса» |
|---|---|---|---|
| 01 | **Ау** | АУДИТОРИЯ | 28 |
| 02 | **Оф** | ОФФЕРЫ | 22 |
| 03 | **Ст** | СТРАНИЦА | 34 |

Состояния клетки:
- **заперта** — фон `--bg-panel`, рамка `--line`, весь текст `--ink-faint`, поверх иконка замка;
- **активна** — рамка `--line-acid`, символ `--acid`;
- **получена** — рамка `--sky`, символ `--sky`, лёгкая подложка `--sky-dim`.

Клетка используется везде: подводка к модулю, сцена разблокировки, инвентарь, финальная цепочка,
продающий экран. Один объект, проходящий через всю воронку, — это и есть узнаваемость.

### 6.2 Синтез (`ModuleChain`)
Финальная сборка — не «карточки съезжаются», а **реакция**: три клетки элементов сходятся,
между ними прорисовываются связи, по связям проходит импульс, на выходе — соединение,
подсвеченное `--sky`. Кульминация приложения, делается лучше всего остального.

### 6.3 Формула (`CodeInput`)
Ключевое слово вводится как формула соединения: утопленные слоты в моно, подпись `ФОРМУЛА`.
Ошибка — `--bad` + shake + очистка. Успех — каскад `--acid`, затем клетка модуля
переходит в состояние «получена» и загорается `--sky`.

### 6.4 Колодец показаний (`Well`)
Утопленная область `--bg-sunken`, верхняя грань, внутри крупные моно-числа.
Счётчик утечки — `--rust`. Обязательный дисклеймер моно-мелким: `ОЦЕНКА. НЕ ОБЕЩАНИЕ.`

### 6.5 Прогресс (`ProgressRail`)
Тонкая шкала сверху. Показывает **только долю пройденного пути** — никаких фаз, никаких
подписей механики прогрева. Допустимо показывать количество полученных элементов (0/3).

### 6.6 Зерно и свет
Зерно поверх всего: `feTurbulence`, `opacity: 0.03`, `mix-blend-mode: overlay`.
Плюс очень слабое тёплое пятно света сверху экрана (радиальный градиент от
`rgba(196,85,29,0.05)` к прозрачному) — натриевый фонарь над пустыней.
Оба — `position: fixed`, `pointer-events: none`, один раз в шелле.

## 8. ДВИЖЕНИЕ

Пружины и длительности — только из `src/lib/motion.ts`.

```ts
springSnappy = { type:'spring', stiffness: 420, damping: 34, mass: 0.85 }
springPanel  = { type:'spring', stiffness: 280, damping: 32, mass: 1.0 }
springSoft   = { type:'spring', stiffness: 180, damping: 26, mass: 1.1 }
easeOut      = [0.16, 1, 0.3, 1]
```

- Переход экрана: исходящий `opacity→0, x→-16` 160ms; входящий `x 20→0` со `springPanel`.
- Список: stagger 40ms, `y 10→0`.
- Разблокировка модуля: каскад слотов → клетка перекрашивается в `--sky` → импульс по грани.
- Haptics обязательны: `light` — выбор, `medium` — первичная CTA, `success` — верный код
  и полученный элемент, `error` — неверный код, `select` — переключение.
- `prefers-reduced-motion`: остаётся только `opacity` 120ms, счётчики ставят финал сразу.

## 9. ДОСТУПНОСТЬ

- Тап-таргеты ≥ 44×44px, зазор ≥ 8px.
- `:focus-visible` — `outline: 2px solid var(--acid); outline-offset: 2px`.
- Только нативные `<button>` / `<input>`.
- Спроектированы все состояния: loading, empty, error, disabled.
- `overflow-wrap: anywhere` на контейнерах текста.
- Тема Telegram игнорируется намеренно: приложение принудительно тёмное и брендированное
  (`setHeaderColor` / `setBackgroundColor` читают реальное значение `--bg-void`).
