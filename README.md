# ЛАБОРАТОРИЯ — Telegram Mini App

Геймифицированная обучающая воронка прогрева для перформанс-маркетологов.
Ведёт человека по механике **ЗНАЮ → ХОЧУ → ВЕРЮ → ПЛАЧУ** к покупке технического
практикума за 3 990 ₽.

## Документы проекта

| Файл | Что внутри |
|---|---|
| `DESIGN.md` | Визуальный мир, токены, запреты, спецификации компонентов, движение |
| `PRODUCT.md` | Продуктовая логика, игровые системы, карта экранов, аналитика |
| `ARCHITECTURE.md` | Стек, дерево файлов, контракты типов и сигнатур |
| `BRIEF.md` | Исходный авторский копирайт (источник правды по текстам) |

---

## Запуск

```bash
npm install
npm run dev        # локально, вне Telegram — работает с браузерными заглушками
npm run build      # прод-сборка
npm run preview
npm run typecheck
```

Приложение открывается и вне Telegram: обёртка `src/lib/telegram.ts` подставляет
no-op для haptics, BackButton и прочего WebApp API.

## Дизайн-направление

**Не** sci-fi HUD и **не** киберпанк — это то, во что скатывается любой запрос
«ИИ-лаборатория», и это визуальный шум. Взято другое: **точный измерительный прибор
полевой лаборатории**.

Контраст между грубым разговорным копирайтом («бабки», «херня», «головой об Enter
ударился») и хирургически точным приборным интерфейсом — это и есть айдентика.
Интерфейс никогда не шутит. Он замеряет.

### Анти-референсы

Sci-Fi HUD · Cyberpunk · Matrix · AI-фиолетовый градиент · glassmorphism на всём ·
мультяшный EdTech.

### Ядро системы

- **Цвет:** холодный графит `#08090B` … `#16191D`, один сигнальный акцент — лаймовый `#C6F24E`.
  `--warn` и `--bad` только семантические (утечка денег / ошибка).
- **Шрифты:** Onest Variable (интерфейс) + JetBrains Mono Variable (лейблы, коды, показания).
  Оба self-hosted, оба с полной кириллицей. Осознанно не Inter.
- **Сигнатура:** калибровочная шкала `TickRail`, маркировка узла `NodeLabel`,
  утопленный колодец показаний `Well`, верхний блик панели вместо теней, зерно поверх всего.

## Игровой слой

| Система | Что делает |
|---|---|
| **УТЕЧКА** | Счётчик потерянных денег ₽/мес. Считается из ответов теста и специализации, уменьшается с каждым закрытым модулем. Всегда с дисклеймером «ОЦЕНКА. НЕ ОБЕЩАНИЕ.» |
| **КАЛИБРОВКА** | Прогресс 0–100% в верхнем рельсе с открытым показом фазы воронки |
| **МОДУЛИ** | Три запертых модуля, открываются кодами `БРИФ` / `ФОРМУЛА` / `ENTER` |
| **ЦЕПОЧКА** | Кульминация: три модуля стыкуются в одну систему — визуальное доказательство тезиса воронки |

### Интерактивные механики

1. **BriefDecoder** — строка брифа «мужчины и женщины 25–55» распадается на 4 реальные ситуации
2. **BullshitDetector** — найди воду в анализе от нейронки (ключевая обучающая механика)
3. **LeakScanner** — какие сегменты воронки ты вообще контролируешь
4. **FormulaForge** — собери оффер по AIDA / PAS / FAB
5. **BeforeAfter** — шторка сравнения посадочной до и после
6. **ModuleChain** — сборка цепочки

## Что нужно подключить перед запуском в прод

Всё ниже вынесено в конфиг и работает с безопасными заглушками.

### 1. Видео — `src/content/video.ts`

Пять роликов: подводка «не верь мне», три основных, финальный переход.
Проставь `poster` и `src`. `VideoBlock` уже считает долю просмотра и пишет её в стор
(`videos[id]`), события `video_start` / `video_progress` / `video_complete` уходят в аналитику.

### 2. Оплата — `VITE_CHECKOUT_URL`

Кнопка оплаты вызывает единый обработчик. Варианты подключения:
внешняя ссылка на кассу через `openLink()` либо Telegram Invoice через бота.
Сейчас — заглушка с видимым TODO, приложение не падает.

### 3. Ассистенты — `VITE_ASSISTANT_CA_URL`, `VITE_ASSISTANT_ADS_URL`

Ссылки на ассистента по анализу ЦА и по объявлениям, открываются из экранов практики.

### 4. Аналитика — `VITE_ANALYTICS_URL`

Если задан — события уходят через `navigator.sendBeacon`.
Если нет — буферизуются в `localStorage` и логируются в консоль.
Список событий — в `PRODUCT.md` §7.

**Главный вопрос аналитики:** на каком шаге человек перестаёт думать «прикольно»
и начинает думать «блин, мне это реально нужно». Смотреть на связку
`video_complete` → `code_success` → `mechanic_complete` по каждому модулю.

### 5. Префрейм

Лонгрид-префрейм («Я не буду продавать тебе нейронки») живёт отдельным маршрутом
и предназначен для публикации закрепом в канале. В основной поток воронки не входит.

## Правила, которые нельзя нарушать при доработке

1. Копирайт из `BRIEF.md` — дословный. Не смягчать, не цензурировать, не «причёсывать».
2. Ни одного хардкодного цвета вне `src/styles/tokens.css`.
3. Ни одного магического числа анимации вне `src/lib/motion.ts`.
4. `prefers-reduced-motion` уважается везде.
5. Никаких эмодзи в интерфейсе. Иконки — только Phosphor.
6. Никаких обещаний конкретного дохода. Счётчик утечки — всегда «оценка».
